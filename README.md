# Extension Chrome - AREDL & Pointercrate Stats Sync

Cette extension Chrome vous permet de synchroniser vos niveaux complétés et statistiques personnelles depuis votre Google Spreadsheet avec les sites **[aredl.net](https://aredl.net)** et **[pointercrate.com](https://pointercrate.com)**.

## Caractéristiques

### AREDL (`aredl.net`)
- **Synchronisation automatique / 1-clic** avec votre Google Spreadsheet.
- **Badges de complétion (✔ GG)** affichés directement dans la liste des niveaux sur AREDL.
- **Card de statistiques personnelles** insérée sur la fiche détaillée du niveau (Tentatives, Pire fail, Enjoyment, Rating, Notes personnelles).

### Pointercrate Demonlist & Stats Viewer (`pointercrate.com`)
- **Surlignage en vert** des démons complétés sur la liste Demonlist (`/demonlist/`).
- **Profil personnalisé `Ulyxx3` 🇫🇷** injecté dans le **Stats Viewer** (`/demonlist/statsviewer/`) :
  - Calcul dynamique du total de points Demonlist basé sur les niveaux du Top 150 battus.
  - Positionnement automatique et rang dans le classement global.
  - Fiche profil complète listant tous les démons complétés avec leurs points individuels.

## Installation

1. Téléchargez ou clonez ce dépôt sur votre machine.
2. Ouvrez Google Chrome et accédez à `chrome://extensions/`.
3. Activez le **Mode développeur** (interrupteur en haut à droite).
4. Cliquez sur **Charger l'extension non empaquetée** (ou rechargez l'extension si déjà installée).
5. Sélectionnez le dossier `aredl-extension`.

## Utilisation

1. Cliquez sur l'icône de l'extension dans la barre d'outils de Chrome.
2. Collez l'URL de votre Google Spreadsheet (si différente de l'URL par défaut).
3. Cliquez sur **Synchroniser**.
4. Naviguez sur [aredl.net](https://aredl.net) ou [pointercrate.com/demonlist/statsviewer/](https://pointercrate.com/demonlist/statsviewer/) pour voir vos accomplissements en direct !
