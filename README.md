# Extension Chrome - AREDL Personal Stats Sync

Cette extension Chrome vous permet de synchroniser vos niveaux complétés et statistiques personnelles depuis votre Google Spreadsheet avec le site [aredl.net](https://aredl.net).

## Caractéristiques

- **Synchronisation automatique / 1-clic** avec votre Google Spreadsheet.
- **Badges de complétion (✔ GG)** affichés directement dans la liste des niveaux sur AREDL.
- **Card de statistiques personnelles** insérée sur la fiche détaillée du niveau (Tentatives, Pire fail, Enjoyment, Rating, Notes personnelles).

## Installation

1. Téléchargez ou clonez ce dépôt sur votre machine.
2. Ouvrez Google Chrome et accédez à `chrome://extensions/`.
3. Activez le **Mode développeur** (interrupteur en haut à droite).
4. Cliquez sur **Charger l'extension non empaquetée**.
5. Sélectionnez le dossier `aredl-extension`.

## Utilisation

1. Cliquez sur l'icône de l'extension AREDL dans la barre d'outils de Chrome.
2. Collez l'URL de votre Google Spreadsheet (par défaut, l'URL exemple est déjà configurée).
3. Cliquez sur **Synchroniser**.
4. Naviguez sur [aredl.net](https://aredl.net) pour voir vos statistiques s'afficher en temps réel !
